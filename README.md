# .github

Default [community health files](https://docs.github.com/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for `conorbronsdon` repositories.

## Do not add FUNDING.yml here

An account-level default `FUNDING.yml` applies to **forks too**, which puts a
sponsor-me button on other maintainers' projects. Sponsor config stays per-repo
in each owned, non-fork repository (`.github/FUNDING.yml`).

See `docs/repo-launch-checklist.md` in personal-context for the standing rule.
