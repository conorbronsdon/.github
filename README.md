# .github

Default [community health files](https://docs.github.com/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for `conorbronsdon` repositories.

`FUNDING.yml` here applies to every public repo that does not define its own
`.github/FUNDING.yml` — including archived repos, which cannot be pushed to.
A per-repo file always takes precedence over this default.
